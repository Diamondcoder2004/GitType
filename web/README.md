# GitType Web - Тренажёр слепой печати кода

Веб-приложение для тренировки слепой печати на реальном коде из GitHub-репозиториев в стиле **Monkeytype**.

## Запуск

```bash
cd web
npm install
npm run dev
```

Приложение откроется на http://localhost:3000

## Возможности

- 🔗 **Подключение к GitHub** - загрузка кода из любых публичных репозиториев
- 🎨 **Monkeytype-подобный интерфейс** - минималистичный дизайн, тёмная тема
- ⚡ **Статистика в реальном времени** - WPM, точность, ошибки, время
- 🎯 **Фильтр по языкам** - выбор конкретного языка программирования
- 💾 **Сохранение токена** - GitHub токен сохраняется в localStorage
- ⌨️ **Подсветка символов** - зелёный (верно), красный (ошибка), курсор

## Как использовать

1. Введите GitHub токен (создать на https://github.com/settings/tokens)
2. Введите репозиторий в формате `owner/repo` (например: `facebook/react`)
3. Выберите файл с кодом из списка
4. Начните печатать код
5. Получите статистику после завершения

## Горячие клавиши

- **Tab** - перезапуск текущего теста
- **Клик по полю** - фокус на ввод
