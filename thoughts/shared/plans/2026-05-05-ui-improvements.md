# Plan: UI Improvements for GitType

**Date:** 2026-05-05
**Status:** Design Approved ✅
**Source:** octto brainstorm session (ses_5ilpjkjy)

## Problem Statement

GitType — тренажёр слепой печати на реальном коде из GitHub-репозиториев. Текущий UI функционален, но требует визуального обновления и улучшений для лучшего пользовательского опыта.

## Findings by Branch

### 1. Визуальный стиль: modern-clean 🎨

**Выбор:** Современный минималистичный интерфейс с акцентом на чистоте линий, воздухе и удобстве чтения кода.

**Принципы дизайн-системы:**
- Плоские элементы, без излишних теней и градиентов
- Чистая типографика (моноширинный шрифт для кода, sans-serif для UI)
- Упор на контраст и читаемость кода
- Пространство (воздух) между элементами

### 2. Улучшения тренажёра: живая статистика ⌨️

**Формат:** Оверлей поверх редактора кода

**Минимальный режим (всегда виден):**
- WPM (слова в минуту)
- Accuracy (точность в процентах)
- Компактная панель, не перекрывающая код

**Расширенный режим (по наведению/клику):**
- WPM
- Accuracy (%)
- Таймер сессии
- Прогресс (%)
- Счётчик ошибок
- Keystrokes (нажатия клавиш)
- Легенда, поясняющая каждую метрику

### 3. Навигация и настройки: без изменений 🧭

Текущий режим переключения между экранами (выбор репозитория / тренажёр) и расположение настроек остаются без изменений. Пользователя устраивает.

### 4. Система тем: адаптивная 🎭

**Изменения:**
- Сохранить существующие 6 тем через CSS variables
- Добавить автоматическое переключение на основе `prefers-color-scheme` (системные настройки ОС)
- В будущем: поддержка большего количества тем

### 5. Дополнительное требование (из feedback)

> «Нужен прогресс по репозиторию — всё-таки мы учим репозитории и писать продакшен код, а не тренируем только слепую печать»

**Прогресс по репозиторию:**
- История тренировок привязана к репозиторию
- Статистика: какие файлы/языки пройдены, WPM по репозиторию
- Прогресс по файлам в репозитории (% завершённых файлов)
- Возможность отслеживать улучшение WPM по конкретному файлу со временем

## Implementation Recommendations

### Фаза 1: Дизайн-система + темы
1. Переработать CSS variables под modern-clean стиль
2. Добавить `prefers-color-scheme` media query
3. Обновить базовые компоненты (цвета, отступы, типографика)

### Фаза 2: Оверлей статистики
1. Разработать компонент `StatsOverlay` (мини + расширенный режим)
2. Интегрировать с typingEngine для реального времени
3. Добавить legend tooltip для метрик

### Фаза 3: Прогресс по репозиторию
1. Продумать модель данных (repositoryId, fileId, WPM, accuracy, дата)
2. Хранить историю в localStorage/Zustand
3. UI: страница/вкладка прогресса по репозиторию
